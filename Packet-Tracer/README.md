# Packet Tracer

Prácticas y laboratorios de Cisco Packet Tracer organizados por tema.

| Carpeta | Contenido |
|---|---|
| `01-Topologias-y-Arquitecturas` | Topologías físicas/lógicas (estrella, bus, anillo, malla, híbrida) y arquitecturas jerárquicas y de campus |
| `02-Defensa-de-Red` | ACLs, Port Security, ASA, firewall por zonas, VPN IPsec, AAA, hardening, seguridad de capa 2, IDS/IPS |
| `03-Enrutamiento` | Estático, RIP, OSPF, EIGRP, BGP |
| `04-Conmutacion-y-VLANs` | VLANs, trunking, Inter-VLAN, STP, EtherChannel, HSRP |
| `05-Servicios-de-Red` | DHCP, DNS, NAT/PAT, Web/FTP/Email, NTP y Syslog |
| `06-Redes-Inalambricas` | WLAN básica, WLC y APs ligeros |
| `07-IPv6` | Direccionamiento y enrutamiento IPv6 |
| `08-WAN-y-Conectividad` | PPP/HDLC y túneles GRE |
| `09-IoT-y-Redes-Industriales` | Hogar inteligente, smart city e industria |
| `10-Troubleshooting` | Escenarios de fallas y diagnóstico |
| `11-Proyectos-Integradores` | Proyectos que combinan varios temas |
| `Plantillas` | Archivos base y formato de documentación |

## Contenido de cada práctica

- Archivo `.pkt`
- Capturas de la topología
- Configuraciones de los dispositivos
- Notas y conclusiones

Cada carpeta tiene un `placeholder.txt` provisional; reemplázalo o elimínalo cuando agregues el contenido real.
